About CEOIS

Our Project

CEOIS is a software prototype designed to help community members view manually maintained, area-wise electricity outage announcements and submit power-supply problem reports.

Main Features

  • View outage announcements maintained by an administrator.
  • Filter announcements by area.
  • Submit power-cut reports.
  • Track submitted reports using a unique Report Tracking ID and check their current status.
  • Review reports and update report status in the admin dashboard.
  • Manage outage announcements through the admin area.
  • View aggregate community-report counts without exposing reporter details publicly.
Project limitation: CEOIS does not provide live electricity-provider data or real SMS notifications. No reports does not mean electricity is available.
